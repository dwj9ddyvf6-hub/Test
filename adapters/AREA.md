# adapters/: what lives here

Standalone desk adapters for recently built sleeves (one-bar, Trullas variants, Teddy ORB, PRZM and others), one file per sleeve.

Exact file count, byte total and captured revision: [the generated repository index](../INDEX.md). The matching entries in [INDEX.json](../INDEX.json) retain every path and blob hash.

All 30 files sit at the top of this folder, one adapter per sleeve. There are no subfolders.

## Where its index lives

- Every file in this area is listed, with size and blob sha, in the root INDEX.json (search it by the path prefix `adapters/`).
- The prose map is the root INDEX.md; the mandatory first read is the root START-HERE.md; routing by topic is the root ROADMAP.md.
