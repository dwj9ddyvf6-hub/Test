# przm_zero: Recreation package

Provenance: PRZM (przm.space) public record: Flight Manual V201 and the public client fallback engine, recreated per PRZM-RECREATION-SPEC-2026-10-29 (Source row in strategies/muse/muse-przm-zero.md in this repo; the spec's Source line is: Source: TEARDOWN.md (PARTIAL) in this directory; evidence manifest evidence/meta/capture_manifest.sha256 (6,788 entries). Public material only.)

## What this sleeve is
This is a parked, paper-only SPY recreation of the PRZM Zero same-day lean engine: signed SPY options prints are weighted, bucketed and blended into a five-driver score whose hysteresis calls long, short or stand-aside. Because no desk producer serves a signed same-day print tape, it currently ledgers the price driver only, emits no lean and trades nothing.

## Full algorithm
The strategy logic is in sleeves/przm_zero.py and delegates to no desk3 engine. Constants: SYMBOL SPY, ENTRY_SCORE 25, FLIP_SCORE 35, DROP_SCORE 8, MIN_HOLD_MS 600000, GRADE_AFTER_MS 1800000, window 09:45 to 15:45 ET, NOTIONAL_PER_CALL $1,000, CHASING_MULT 0.55, CONTRARIAN_MULT 1.25, CHASING_M5_MIN 0.8.
Waiting state first, in signal(): state is per-day przm_state {direction, since_ms, calls, open_call}. If ctx.extra przm_prints is empty / absent, last_evaluation is WAITING_NO_PRINT_TAPE (with px_30m_move = latest close minus the close 31 bars earlier when at least 31 of today's RTH bars exist) and the sleeve returns no intents; it grades nothing and makes no call.
Print weight (print_weight): 0 if bull is falsy or the print is mid; else base w by absolute delta / price: 0.15 if abs(delta) < 0.1, or price < 0.12 and abs(delta) < 0.2; else 0.2 if it is a put bought at ask with abs(delta) < 0.25 and otm_frac > 0.6; else 0.5 if abs(delta) > 0.85; else 1. Multipliers, only when the tape natively carries the flags: sweep x1.35, opening x1.25, closing x0.7. If m5 (SPY 5-candle move in volatility units for that print) is present and abs(m5) > 0.8, w x0.55 when the print agrees with m5 (chasing) and x1.25 when it disagrees (contrarian). Paired-leg cancellation is dropped, stated in the module, not approximated. Signed value per print = bull * abs(delta) * size * 100 * spot * w; delta is Black-Scholes ncdf(d1) with IV defaulting to 0.16 when out of (0.01, 5.0).
Drivers (compute_drivers / bucketize): prints are bucketed into 5-minute buckets of (net, abs) signed value. Shares are net/abs over: SES = all buckets today, 30M = last 1800 s, 10M = last 600 s, 5M = last 300 s. F = 0.3*SES + 0.4*30M + 0.22*10M + 0.08*5M. STDY = fraction of the last 4 non-empty buckets whose net sign agrees with F (and is non-zero). PX = tanh((spot - c30)/c30 / (v1 * sqrt(30)) / 1.5), where c30 is the close 31 bars back and v1 is the root-mean-square 1-minute log return today. x = F * (0.7 + 0.3*STDY); if F and PX agree in sign, x *= 1 + 0.15*abs(PX), if they disagree x *= 1 - 0.25*abs(PX). Regime pin (from ctx.extra przm_regime): x *= 0.85 and x += 0.18 * clamp((magnet - spot) / max(0.05, expected_move), -1, 1); regime run: x *= 1.15. Before 10:00 ET x *= 0.75; at or after 15:45 x *= 0.6. score = round(clamp(x, -1, 1) * 100). Drivers are reported rounded x100.
Hysteresis (CallMachine.update), applied only inside 09:45 to 15:45 ET: from neutral, score >= 25 enters long (+1) and score <= -25 enters short (-1), recording since_ms; from a direction, an opposing score * -direction >= 35 flips the direction and resets since_ms; a drop (score * direction < 8 AND at least 600000 ms since the call) returns to neutral. Otherwise the direction is unchanged.
Execution (recreated share proxy): on a changed non-zero direction with no open quantity and no exit emitted in the same call, append the call {t_ms, px=spot, direction} to calls / open_call and emit one enter Intent on SPY, qty = max(1, int(1000 // spot)), price_hint spot, side buy / buy_to_open for long and sell / sell_to_open for short, reason naming przm_zero, the direction, score and all five drivers. Exit: if quantity is open and (time is at or after 15:45, or the call changed to a different direction than the position), emit one full exit Intent (sell_to_close / buy_to_close) and clear open_call. Grading helpers (not traded): grade_call is sign-only at +30 minutes and a zero move grades WRONG; grade_ledger counts right, wrong and pending separately.

## Data inputs
Inputs are bars / bars_1min / bars:SPY:1Min (SPY 1-minute bars for today, RTH), options and options_chain, positions, quotes and session_fills. The strategy consumes bars[SPY] (today's closes), ctx.now, ctx.session, the held SPY quantity in slice_state, and ctx.extra przm_prints (the signed print tape: each print with bull, delta, price, size, is_call, bought_at_ask, otm_frac and optionally sweep / opening / closing / mid), plus optional ctx.extra przm_regime, przm_magnet and przm_expected_move. No przm_prints means the WAITING_NO_PRINT_TAPE state above, by design.

## Install and run
1. Place the sleeve module and adapter at the paths listed under Files in this repo, and place every listed shared engine file at its listed repo path (sleeves/muse/core/sleeve.py is core/sleeve.py on a fresh desk; sleeves/trullas_divergence.py and sleeves/investandbefree_dmac.py are the same paths on a fresh desk).
2. Register the config row for `przm_zero` from engines/config/sleeves.json (repo copy of config/sleeves.json, also at config/sleeves.json) in the fresh desk's config/sleeves.json, exactly as given in the Configuration section, with no parameter overrides.
3. Wire the producers named in Data inputs so the inputs listed in the Configuration section arrive in the cycle snapshot (view) in the shapes the Full algorithm section describes.
4. Entry point: the adapter module adapters3/przm_zero.py, whose evaluate(view, ctx) builds a SnapshotSleeveContext and delegates to adapters/przm_zero.py, which runs sleeves/przm_zero.py signal(bars, slice_state, context).
5. First evaluation: run one cycle on a fixture snapshot that satisfies the entry conditions in the Full algorithm section and confirm the expected intent (symbol, side, quantity rule and reason string naming this sleeve) is emitted before enabling live paper routing. If the Configuration section says parked is true, keep the sleeve parked exactly as in that row; the waiting behaviour in the Full algorithm section is the expected behaviour until its named input route is proven.

## Verification
- Run tests/test_przm_recreation_blockers.py in this repo: hand-worked equalizer score, chasing ratio 0.55 and contrarian 1.25, hysteresis holds / flips / drops and the WAITING state must all pass.
- Fixture with no przm_prints: no intent, last_evaluation state WAITING_NO_PRINT_TAPE, and only the PX note is ledgered.
- Fixture with prints producing score >= 25 inside 09:45 to 15:45 ET and no open position: exactly one long enter Intent, qty max(1, int(1000 // spot)), reason naming przm_zero with score and drivers. Score <= -25 gives the mirrored short.
- Fixture with an open call: an opposing score of 20 or 34 does not flip, 35 or more flips (exit emitted); a fade to score * direction < 8 before 600000 ms holds, and at or after 600000 ms drops to neutral with a full exit; at or after 15:45 ET an open position is force-closed.
- Grading fixture: a call graded at +30 minutes with a favourable move is RIGHT, an adverse or zero move is WRONG, and both are counted, with ungraded calls reported as pending.
- The config row used by the recreation matches engines/config/sleeves.json for przm_zero (module, cadence, session, slice, parked true with the named reason, and inputs).
