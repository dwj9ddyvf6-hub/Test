# trullas_v08: Recreation package

Provenance: Trullas method research (GrokBot track), built from the REA teardown record. Code: sleeves/trullas_divergence.py. Doc: Author spec on file in this repo. (Provenance line in docs/TRULLAS-VARIANTS-SPEC-2026-10-29.md in this repo.)

## What this sleeve is
This is a paper-only QQQ 1-minute divergence sleeve, a thin subclass of the primary Trullas divergence sleeve with exactly one joint changed: one pyramiding add on strength. It is otherwise the primary's Fib divergence machinery, on its own $10,000 slice and record, with no backtest.

## Full algorithm
This sleeve is a thin wrapper: sleeves/trullas_v08.py defines TrullasV08Sleeve(TrullasDivergenceSleeve) with PARAMS = variant_params(pyramid=True) and REASON_LABEL trullas_v08; every other field keeps its primary value (pivot_k=5, tp2_level=0.618, include_hidden=False, rsi_zone_only=False, fallo_admitted=False, vol_window=0, require_all_three=False).
Variant joint, in _manage() only: if PARAMS.pyramid, the plan has not added and TP1 has not been done, and R = abs(entry - stop_orig) is positive, then when price first moves 0.5R in favour (bearish latest low <= entry - 0.5*R; bullish latest high >= entry + 0.5*R), emit one additional enter Intent for add_qty = floor(min(0.0025 * equity / R, 0.25 * equity / entry)) (0 if equity is unavailable, in which case no add), set added=True, increase qty_initial by add_qty, and move the whole position's stop to the entry price. This add block is evaluated after the stop check and before TP1; there is never a second add.
Common engine, as applied (sleeves/trullas_divergence.py, PRIMARY_PARAMS unless the variant joint above changes a field): pivots are strictly highest high / lowest low over a 2k+1 window with k=5, usable only at confirm_index = pivot index + 5. Pairs are two consecutive confirmed pivots of the same kind, same trading day, 10 to 120 bars apart. MACD(12,26,9) is EMA-based (seed = simple mean of the first period values) read on the MACD line; RSI(14) is Wilder. RTH filter: only bars 09:30 to 16:00 ET with volume > 0, sorted and de-duplicated; zero-volume bars are dropped.
Regular divergence: bearish (pivot highs) price second > first, MACD second < first, RSI second < first, volume second < first; bullish (pivot lows) price second < first, MACD second > first, RSI second > first, volume second < first (the code's regular volume test). MACD divergence is REQUIRED (macd_ok); divergence count = int(macd_ok) + int(rsi_div) + int(vol_div), 1 to 3.
Fibonacci geometry: bearish A = lowest low between the two highs, B = second pivot high, level(p) = B - p*(B-A); bullish A = highest high between the two lows, B = second pivot low, level(p) = B + p*(A-B). Entry trigger = level(0.236) minus $0.01 (bearish) / plus $0.01 (bullish); stop = B plus $0.01 / minus $0.01; TP1 = level(0.382); TP2 = level(0.618) unless the variant joint changes it.
Evaluation order in signal(): (1) If a position is open and a plan exists, manage it (see exits below) and return; if a position is open with no plan, only the 12:00 ET flat is emitted, otherwise nothing. (2) Refresh the pending setup to the newest setup for this session whose confirm_t is at or before the latest bar and whose pivot pair was not already traded. (3) Expire the pending setup after 30 bars since confirmation, or void it if the latest bar trades beyond swing B plus / minus $0.01. (4) Entry gates in order: latest bar time in 09:30 to 11:00 ET, entries_today < 5, equity > 0, realized_pnl > -0.0075 * equity (daily loss stop -0.75%). (5) Trigger: bearish latest low <= entry_trigger, bullish latest high >= entry_trigger. Fill price is the entry_trigger. Sizing: risk_per_share = abs(stop - fill); qty = floor(min(divergence_count * 0.0025 * equity / risk_per_share, 0.25 * equity / fill)); qty <= 0 emits nothing. The entry Intent is enter on QQQ with stop and target TP2, exit_rules stop and target TP2, side sell / position_intent sell_to_open for direction -1 and buy / buy_to_open for direction +1, reason starting with the sleeve REASON_LABEL.
Exits in _manage(), in order: hard flat at or after 12:00 ET (full exit at the latest close, realised P&L booked); then stop hit (bearish latest high >= stop, bullish latest low <= stop; pessimistic ordering, stop before any target in the same bar); then (v08 only) pyramiding; then TP1 if not done (bearish latest low <= TP1, bullish latest high >= TP1): exit max(1, floor(abs(qty)/2)) shares if abs(qty) >= 2, otherwise the full quantity; if a remainder stays, tp1_done = True and stop moves to the entry price; then, only if tp1_done, TP2 (same touch test against TP2) for the full remainder. State (day, entries_today, realized_pnl, pending, plan, traded_pairs) is carried in ctx.extra trullas_state and round-tripped by the adapter.

## Data inputs
Inputs are bars, bars_1min and bars:QQQ:1Min (QQQ 1-minute SIP bars {t,o,h,l,c,v} from the warm bars product), positions, quotes and session_fills. The strategy itself consumes bars[QQQ] through the adapter context, ctx.session, ctx.now (ET clock), ctx.equity (slice equity) and ctx.extra trullas_state (pending setup, open-trade plan, day counters round-tripped by the adapter from its own state file). No bars means last_evaluation state no_bars and no intent.

## Install and run
1. Place the sleeve module and adapter at the paths listed under Files in this repo, and place every listed shared engine file at its listed repo path (sleeves/muse/core/sleeve.py is core/sleeve.py on a fresh desk; sleeves/trullas_divergence.py and sleeves/investandbefree_dmac.py are the same paths on a fresh desk).
2. Register the config row for `trullas_v08` from engines/config/sleeves.json (repo copy of config/sleeves.json, also at config/sleeves.json) in the fresh desk's config/sleeves.json, exactly as given in the Configuration section, with no parameter overrides.
3. Wire the producers named in Data inputs so the inputs listed in the Configuration section arrive in the cycle snapshot (view) in the shapes the Full algorithm section describes.
4. Entry point: the adapter module adapters3/<this sleeve>.py, whose evaluate(view, ctx) builds a SnapshotSleeveContext and delegates to adapters/<this sleeve>.py, which runs sleeves/<this sleeve>.py signal(bars, slice_state, context).
5. First evaluation: run one cycle on a fixture snapshot that satisfies the entry conditions in the Full algorithm section and confirm the expected intent (symbol, side, quantity rule and reason string naming this sleeve) is emitted before enabling live paper routing. If the Configuration section says parked is true, keep the sleeve parked exactly as in that row; the waiting behaviour in the Full algorithm section is the expected behaviour until its named input route is proven.

## Verification
- Run tests/test_trullas_variants_blockers.py in this repo and proof/install checks: the config row shape and INPUTS must match the Configuration section, and on the golden fixture this variant must differ from the primary only as its named joint dictates and match the primary where the joint is inert.
- Fixture with an open plan whose latest bar reaches +0.5R before TP1 and does not hit the stop: exactly one pyramid add of 1 unit on the sizing formula above, the plan stop moves to entry, and no second add is emitted on a later bar. A bar that hits the stop takes the stop exit instead of the add.
- Fixture with no qualifying divergence, a setup aged over 30 bars, a trade beyond swing B plus / minus $0.01, an entry time outside 09:30 to 11:00 ET, 5 entries already today, or realised P&L at or below -0.75% of equity: no entry.
- Fixture with a held position: a bar at or after 12:00 ET exits in full first; a bar spanning both stop and a target takes the stop; a TP1 touch exits half (floor) and moves the stop to entry; a later TP2 touch exits the remainder.
- The config row used by the recreation matches engines/config/sleeves.json for this sleeve id (module, cadence, session, slice, parked state and inputs).
