# Demonstration: Three Worked Reads Under the Reading Protocol

Date of reads: Friday 2026-10-30.

## Data honesty statement

Every number in this document was computed in this run from one on-disk source: `~/workspace/morgue/data_cache/board_bt_bars.json`, daily bars in the form date, open, high, low, close, volume. The file holds 403 daily bars per name here, from 2025-03-25 to a last bar dated 2026-10-29. All three names below were read from that same file, and the last bar date for each read is 2026-10-29. Averages are simple averages of closes computed from the bars read: 20, 50 and 200 session. ATR(14) was computed from the bars read using true range. RSI(14) was computed from closes in this run in simple average form and is labelled as such wherever it appears; it is a context number, not a trigger. Swing highs and lows are 5 bar fractal pivots and recent extremes taken from the bars read, with dates. No price, level or average in this document comes from memory, from a web page, or from any other file. No name failed to read: SPY, QQQ and AAPL were all present in the source with full 403 bar histories, so no substitution was needed.

Each read follows the protocol end to end: trend and structure, levels with numbers, pattern or an honest none, confluence, buy zone, invalidation, targets with R, expected path in words, and what would change the read. All reads are paper only. A read is not an order.
