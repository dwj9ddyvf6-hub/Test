## Class 1: Public GitHub code (22 sources)

1. TA-Lib, C core. https://github.com/TA-Lib/ta-lib . The de facto software definition of candlestick reading: 61 CDL pattern functions plus 150 plus indicators. Teaches that every pattern is a set of measurable body, shadow, and range comparisons. Listed for the C repo itself; rules corroborated by read sources below.
2. mrjbq7/ta-lib, Python wrapper. https://github.com/mrjbq7/ta-lib . How practitioners actually call the canon in Python; the README enumerates the full 61 pattern names. Listed.
3. serkor1/ta-lib-R, R port and candlestick vignette. https://github.com/serkor1/ta-lib-R/ . Read in full. The clearest written exposition of TA-Lib internal logic: the reference average system (BodyLong, BodyDoji, ShadowLong, Near, Far, Equal settings with N and alpha values) and the penetration parameter behind the star patterns.
4. pandas-ta (twopirllc) and pandas-ta-classic (xgboosted). https://github.com/twopirllc/pandas-ta ; https://github.com/xgboosted/pandas-ta-classic . The pandas native workflow for the canon; the Classic fork reimplements the CDL patterns in readable Python. Listed; PyPI open blocked by client challenge.
5. Tulip Indicators, tulipy, tulip-rs. https://github.com/TulipCharts/tulipindicators ; https://github.com/cirla/tulipy . A second independent C canon: 104 indicators, with pattern recognition parameterized explicitly (doji max body ratio, long candle minimum height). Listed.
6. finta. https://github.com/peerchemist/finta . 71 to 80 plus indicators in pure pandas; useful for indicator and pivot geometry, not a candlestick canon. Archived 2022. Listed.
7. bukosabino/ta. https://github.com/bukosabino/ta . Pandas momentum, trend, volatility, and volume library; marks the boundary of the pattern canon. Listed only.
8. Sortefi sortefi-ta. https://github.com/Sortefi/sortefi-ta . A deliberately readable modern reimplementation: 121 indicators, 59 candlestick patterns, plus VCP, Cup and Handle, and High Tight Flag, each rule in its own short file. Listed via announcement.
9. eminsk/yfinance-ta-patterns. https://github.com/eminsk/yfinance-ta-patterns . Teaches confluence: a full 61 pattern scan plus a deterministic 0.0 to 1.0 score from EMA alignment, relative volume, RSI, and ATR expansion. Listed.
10. zeta-zetra/chart_patterns. https://github.com/zeta-zetra/chart_patterns . Read via DeepWiki. The cleanest open source textbook for classical patterns: a pivot primitive first, then Head and Shoulders, Triple Top and Bottom, Wedge, Triangle, Rounding Bottom, Rectangle, and Support and Resistance, each with explicit geometry validation including the wedge slope ratio test of 0.75 to 1.25.
11. PatternPy (keithorange/PatternPy, PyPI m-patternpy). https://github.com/keithorange/PatternPy . Read via PyPI page. The screener shaped version of the same canon; its pattern list is itself a lay taxonomy of what a human reader scans for, in order.
12. TradingPatternScanner (white07S). https://github.com/white07S/TradingPatternScanner . README read in full. Adds the denoising lesson: the same Head and Shoulders detector after Savitzky-Golay, Kalman, and wavelet filtering scores differently (wavelet best at 84.5 percent on synthetic data), and window size trades sensitivity against false positives.
13. TechnicalAnalysisAutomation (shuhanchang12, neurotrader888 fork). https://github.com/shuhanchang12/TechnicalAnalysisAutomation . Read via DeepWiki. Three rival ways to choose the points that matter: Directional Change thresholds, Perceptually Important Points, and Rolling Window extrema; Harmonic XABCD detection with exact Fibonacci ratio bands and an error budget.
14. trendln (GregoryMorse). https://github.com/GregoryMorse/trendln . Read in full. The most method complete open source answer to which trendline is right: extrema finders, competing line finders, ranking by slope error and wrong side area, and a drawing protocol of average line plus top two support and top two resistance lines.
15. Fractal support and resistance tutorial notebooks (gianlucamalato/machinelearning and peers). https://github.com/gianlucamalato/machinelearning . The five candle fractal level rule, argrelextrema swing detection, level binning and clustering, volume profile nodes, and multi anchored regression channels. Listed.
16. mplfinance. https://github.com/matplotlib/mplfinance . The Python drawing standard most pattern repos plot with: candle, ohlc, renko, and point and figure types, hlines, tlines, alines, and addplot overlays. Listed; PyPI open blocked.
17. finplot. https://github.com/highfestiva/finplot . Examples wiki read. Interactive high performance plotting for eyeballing large history, with a practitioner idiom worth copying: mark only the top 1 percent of wick extremes so extreme wicks remain events.
18. TradingView Lightweight Charts and lightweight-charts-python. https://github.com/tradingview/lightweight-charts ; https://github.com/louisnw01/lightweight-charts-python . The web drawing standard: series, markers, and a hand drawing Toolbox for trendlines, rays, and horizontals. Listed.
19. foduucom/stockmarket-pattern-detection-yolov8 (Hugging Face). https://huggingface.co/foduucom/stockmarket-pattern-detection-yolov8 . The object detection approach: patterns as bounding boxes with confidence, trained on about 9,000 annotated chart images across 6 classes. Listed via model cards.
20. Stock Chart Pattern Recognition with Deep Learning (arXiv 1608.07774 lineage). CNN recognition of Head and Shoulders, wedges, and double and triple tops and bottoms from rendered chart images. Method history, not runnable canon. Listed.
21. Object Detection Approach for Stock Chart Patterns Recognition (ICSCA 2023). A purpose built image dataset for four patterns; quantifies that raw candle images are hard even for vision models and that segmentation preprocessing is part of the craft. Listed.
22. wilsonfreitas/awesome-quant. https://github.com/wilsonfreitas/awesome-quant . The map of the territory: the canonical indicators reading list this census sampled. Listed. Applied tutorial repos worth a reader time (CanerIrfanoglu/medium candlestick ranking by Bulkowski performance order, CharlieNestor statistical candlestick analysis, DataPatternX candlestick patterns as SQL) are catalogued inside the code census pass.

## Cross class synthesis

- Context before pattern in every class: ChartSchool prior trend rule, Bulkowski price trend row, Wyckoff Step 1, Weinstein forest to trees, RealDayTrading market first, Keller ordered routine.
- Lines need repeated touches to exist: 2 minimum to draw, 3 plus or 5 total to trust, by family.
- No break, no pattern: confirmation is a close beyond the defining line, ideally with volume expansion in the break direction.
- Volume has a script inside every pattern and a divergence is the standard early warning in all five classes.
- Broken levels flip polarity and the retest is a distinct named event everywhere: throwback and pullback, LPS and LPSY, support turned resistance.
- Targets are measured and explicitly provisional, subordinated to the next real level.
- Every read carries an invalidation, and time is an identification rule: duration floors and touch minimums are where most public mislabelling happens.
