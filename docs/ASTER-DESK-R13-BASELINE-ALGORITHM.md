# Aster desk R13 baseline - Algorithm

Created by Ausar. Packaged into the Test repo on 2026-10-29 (packaging pass).

Origin: dwj9ddyvf6-hub/quant-research-backup branch main, research-archives/2026-10-09-trader-strategy-sleeves-r13/desk (location per the Aster collaboration guide).

The R13 baseline desk tree from the Aster trader-strategy-sleeves study archive: the full desk subset of the archive (267 of 1,213 archive files), preserving its relative structure: strategies/ (the sleeve and strategy modules with their research input manifests and tensor_daily20 models), backend/ and frontend/ (the desk application), docs/ (feature, parity, audit and implementation-verification records), tests/, and scripts/. The remaining archive sections (catalogue, backtests, verification, user-evidence, evidence, operating-state) stay in the private backup repo and are not part of this package; the archive root carries ARTIFACT_MANIFEST.json and R13_FINAL_STUDY_RECEIPT.json as its provenance record there.

## Renamed files (privacy gate)

Two source filenames themselves were refused by the public-repo privacy gate because each contains the author's codename, so those two files are packaged under sanitized names; the private originals in dwj9ddyvf6-hub/quant-research-backup are the verbatim source. Renames (codename shown as a bracketed placeholder because the gate also scans this doc): the file named `desk/docs/FEATURES_[codename].json` in the source is packaged as `desk/docs/FEATURES_AUTHOR.json`, and the file named `desk/docs/review-[codename]-infrastructure.json` in the source is packaged as `desk/docs/review-author-infrastructure.json`.
