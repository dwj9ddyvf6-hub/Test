## What this sleeve is
This is a paper-only QQQ 1-minute divergence sleeve, a thin subclass of the primary Trullas divergence sleeve with exactly one joint changed: a trade fires only when all three divergences are present. It is otherwise the primary's machinery, on its own $10,000 slice and record, with no backtest.

## Full algorithm
This sleeve is a thin wrapper: sleeves/trullas_v10.py defines TrullasV10Sleeve(TrullasDivergenceSleeve) with PARAMS = variant_params(require_all_three=True) and REASON_LABEL trullas_v10; every other field keeps its primary value (pivot_k=5, tp2_level=0.618, include_hidden=False, rsi_zone_only=False, fallo_admitted=False, pyramid=False, vol_window=0).
Variant joint, in detect_setups(): after count = int(macd_ok) + int(rsi_counted) + int(vol_div) is computed, a setup with count != 3 is skipped entirely. Every admitted v10 trade therefore has divergence count exactly 3 and sizes at exactly 3 units (subject to the notional cap in the common sizing rule).
Common engine, as applied (sleeves/trullas_divergence.py, PRIMARY_PARAMS unless the variant joint above changes a field): pivots are strictly highest high / lowest low over a 2k+1 window with k=5, usable only at confirm_index = pivot index + 5. Pairs are two consecutive confirmed pivots of the same kind, same trading day, 10 to 120 bars apart. MACD(12,26,9) is EMA-based (seed = simple mean of the first period values) read on the MACD line; RSI(14) is Wilder. RTH filter: only bars 09:30 to 16:00 ET with volume > 0, sorted and de-duplicated; zero-volume bars are dropped.
Regular divergence: bearish (pivot highs) price second > first, MACD second < first, RSI second < first, volume second < first; bullish (pivot lows) price second < first, MACD second > first, RSI second > first, volume second < first (the code's regular volume test). MACD divergence is REQUIRED (macd_ok); divergence count = int(macd_ok) + int(rsi_div) + int(vol_div), 1 to 3.
Fibonacci geometry: bearish A = lowest low between the two highs, B = second pivot high, level(p) = B - p*(B-A); bullish A = highest high between the two lows, B = second pivot low, level(p) = B + p*(A-B). Entry trigger = level(0.236) minus $0.01 (bearish) / plus $0.01 (bullish); stop = B plus $0.01 / minus $0.01; TP1 = level(0.382); TP2 = level(0.618) unless the variant joint changes it.
Evaluation order in signal(): (1) If a position is open and a plan exists, manage it (see exits below) and return; if a position is open with no plan, only the 12:00 ET flat is emitted, otherwise nothing. (2) Refresh the pending setup to the newest setup for this session whose confirm_t is at or before the latest bar and whose pivot pair was not already traded. (3) Expire the pending setup after 30 bars since confirmation, or void it if the latest bar trades beyond swing B plus / minus $0.01. (4) Entry gates in order: latest bar time in 09:30 to 11:00 ET, entries_today < 5, equity > 0, realized_pnl > -0.0075 * equity (daily loss stop -0.75%). (5) Trigger: bearish latest low <= entry_trigger, bullish latest high >= entry_trigger. Fill price is the entry_trigger. Sizing: risk_per_share = abs(stop - fill); qty = floor(min(divergence_count * 0.0025 * equity / risk_per_share, 0.25 * equity / fill)); qty <= 0 emits nothing. The entry Intent is enter on QQQ with stop and target TP2, exit_rules stop and target TP2, side sell / position_intent sell_to_open for direction -1 and buy / buy_to_open for direction +1, reason starting with the sleeve REASON_LABEL.
Exits in _manage(), in order: hard flat at or after 12:00 ET (full exit at the latest close, realised P&L booked); then stop hit (bearish latest high >= stop, bullish latest low <= stop; pessimistic ordering, stop before any target in the same bar); then (v08 only) pyramiding; then TP1 if not done (bearish latest low <= TP1, bullish latest high >= TP1): exit max(1, floor(abs(qty)/2)) shares if abs(qty) >= 2, otherwise the full quantity; if a remainder stays, tp1_done = True and stop moves to the entry price; then, only if tp1_done, TP2 (same touch test against TP2) for the full remainder. State (day, entries_today, realized_pnl, pending, plan, traded_pairs) is carried in ctx.extra trullas_state and round-tripped by the adapter.

## Data inputs
Inputs are bars, bars_1min and bars:QQQ:1Min (QQQ 1-minute SIP bars {t,o,h,l,c,v} from the warm bars product), positions, quotes and session_fills. The strategy itself consumes bars[QQQ] through the adapter context, ctx.session, ctx.now (ET clock), ctx.equity (slice equity) and ctx.extra trullas_state (pending setup, open-trade plan, day counters round-tripped by the adapter from its own state file). No bars means last_evaluation state no_bars and no intent.
