# BUGLOG 2026-10-24 — muse-desk-v3 core platform

Each entry: severity / source / defect / cure / gate-wired blocker.
Fail direction for all CORE blockers proven in-session: the full suite
(21 tests) was written FIRST and ran FAILED (failures=1, errors=20 —
desk3 did not exist) before any implementation; after the cure it runs
OK 21/21 via run_regression_blockers.sh.

- CORE-1 (high, v2 baseline §6 architecture): sequential subprocess-per-
  sleeve evaluation let one wedged sleeve stall the whole cycle (v2:
  21 watchdog kills on 2026-10-23). Cure: bounded persistent WorkerPool
  with per-evaluation HARD timeout; timed-out/crashed worker is killed
  and respawned, sleeve records a wedged verdict, cycle survives.
  Blocker: TestPoolIsolation.test_infinite_loop_cannot_stall_cycle +
  test_crash_kills_and_respawns_worker.
- CORE-2 (high, v2 baseline §6): every sleeve subprocess re-parsed its
  own cache slice and could reach the network at evaluation time. Cure:
  ONE immutable content-hashed snapshot per cycle built by the warm;
  workers load the snapshot only (cached per hash), environment
  stripped, evaluation proven under `unshare -rn` (no network
  namespace). Blockers: TestNoNetworkEval, TestSnapshot,
  TestPoolIsolation.test_worker_env_has_no_secrets.
- CORE-3 (med, new): a half-written or corrupted snapshot could be
  observed mid-cycle. Cure: atomic snapshot save + hash re-verification
  from disk before dispatch; corrupt => cycle fails closed.
  Blocker: TestSnapshot.test_corrupt_snapshot_detected.
- CORE-4 (high, v2 silent-abstention class): a sleeve whose declared
  input was never produced silently abstained. Cure: producer registry
  contract — fed state computed at cycle start; unproduced or stale
  declared input => UNFED, excluded from dispatch, named in
  state/terminal.json + sleeve journal. Blockers: TestRegistryContract
  (phantom / stale / unproduced), TestCycle UNFED exclusion.
- CORE-5 (high, v2 dispatcher semantics preserved + hardened):
  submit ACK must never be a fill; duplicate intents must never
  resubmit; slice buying power checked at intent time. Cure: single
  Dispatcher, v3-<sleeve>-<intent_id> client order ids, journal-indexed
  idempotency, fills ONLY from broker read-back. Blockers:
  TestDispatcher (bp reject / duplicate / read-back fill / pending
  read-back => no fill, no position).
- CORE-6 (med, v2 gap): v2 scheduler kept next-fire in memory — a
  restart could re-fire consumed bars. Cure: scheduler state (next-fire
  + consumed-bar cursors) persisted on disk; restart resumes without
  re-firing. Blocker: TestScheduler (restart no-refire + cursor).
- CORE-7 (critical, posture): nothing in-process stopped a desk pointed
  at live trading. Cure: assert_paper_only refuses ALPACA_ENV=live at
  Desk construction and PaperDoor construction; PaperDoor accepts only
  the paper base URL; gate-wired tree scan proves no real-money
  endpoint string exists. Blockers: TestSecurity (3 tests).
- CORE-8 (low, v2 journal shape): per-intent journal writes were
  unbatched single syscalls on the hot path. Cure: BatchedJournal —
  append-only batched flush, order preserved. Blocker: TestJournal.

- Worker filesystem confinement is by contract + stripped env + state
  dir ctx (no stdlib sandbox exists); network isolation IS enforced
  and proven under unshare. Recorded honestly, not overstated.
