# desk3/: what lives here

The desk3 sleeve collection and its portfolio branches: the v3 desk engine modules, sleeve modules and portfolio books.

Exact file count, byte total and captured revision: [the generated repository index](../INDEX.md). The matching entries in [INDEX.json](../INDEX.json) retain every path and blob hash.

Layout: 20 engine and batch modules at the top, sleeves/ (20 files) and port_b5/ (10 files) beneath. Entry point: the module names at the top of the folder; the roster they serve is config/sleeves.json.

## Where its index lives

- Every file in this area is listed, with size and blob sha, in the root INDEX.json (search it by the path prefix `desk3/`).
- The prose map is the root INDEX.md; the mandatory first read is the root START-HERE.md; routing by topic is the root ROADMAP.md.
