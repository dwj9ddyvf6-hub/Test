# LLM + chart vision repos — notes (read 2026-10-07)

1. qrak/llm_trader — https://github.com/qrak/llm_trader — open-source cognitive crypto trading bot (9 months, by @qrak). KEY FINDING: Phase 1 fed RSI/MACD as text floats to Claude/Gemini → hallucinated trends, -4.2%. Phase 2 deleted 900 lines of pattern heuristics; Plotly renders 1080p chart image (SMA, RSI, Volume, CMF, OBV) fed directly to Gemini Flash; "visual model spots pattern geometry far better than programmatic rules". AGENTS.md documents: prompt strategy = concise instruction asking for structured JSON, base64 PNG (4K, 4-row layout), strip <think> blocks, Pydantic TradingAnalysisResponseModel validation, BUY/SELL requires entry/stop/TP/R:R/position_size; fallback HOLD. PatternEngine: indicator patterns deterministic (Numba), chart patterns visually by LLM. Also has ChromaDB vector memory of past trades, surprise ratio, EV/Kelly gates, falsification gate. Verified live (articles + AGENTS.md).

2. aadisalhotra/llm-trading-lab — https://github.com/aadisalhotra/llm-trading-lab/commit/cd53b8d... — end-to-end pipeline: renders 21 tickers as ONE composite candlestick PNG w/ 20-SMA (matplotlib Agg headless; mplfinance reserved for phase 2). Adapters: BaseAdapter.generate_decision(images=list[bytes]) — Anthropic=image content blocks base64, OpenAI=image_url data URLs, Gemini=inline_data parts, xAI Grok=OpenAI-compatible, DeepSeek text-only. config/settings.json vision_capable flag per model. Prompt builder returns (system, user, version, images); intraday context block tells model ET time, market close, run number, trades used vs 30-day cap (budget so model doesn't dump whole budget). Index-level.

3. alex-jb/orallexa-ai-trading-agent — https://github.com/alex-jb/orallexa-ai-trading-agent — self-tuning multi-agent system, Bull/Bear/Judge debate on Claude. Multimodal: ORALLEXA_MULTIMODAL_SAMPLE env controls fraction of deep-analysis calls where Quant Researcher gets text + K-line chart image; diff stashed on decision_log.extra.multimodal_diff; nightly "Multimodal Lift — Vision vs Text Eval" workflow rolls into ship/reject verdict. Vision ~5x cost per sampled call. This is a published A/B eval pattern: sample-based vision lift measurement. Index-level.

4. HKUDS/vibe-trading PR #464 — https://github.com/HKUDS/Vibe-Trading/pull/464 — `analyze_image` tool: sends image (base64 data URL) + question to chat model, steers LLM to prefer over OCR for charts. Verified live that model reading genuine vision (adversarial test: title said "uptrend" but data trended down → model reported downtrend). Key anti-hallucination technique: adversarial self-test.

5. ArgusOnline01/trading-ai-extension — https://github.com/ArgusOnline01/trading-ai-extension — 0 stars, MIT. Chrome extension + FastAPI; screenshot → GPT-4o/GPT-5 vision for Smart Money Concepts analysis; hybrid vision→reasoning (GPT-4o vision → GPT-5 reasoning), MD5 image cache, trade auto-logging, performance dashboard. Has /prompt endpoint exposing system prompt; docs/SRS.md. Verified live (README).

6. jazzi57/claude-trading-skills — skills/chart-pattern-scanner/SKILL.md (updated 99 days ago) — the best prompt-engineering artifact found. Workflow: (1) vision read of chart image against candlestick_pattern_catalog.md (geometry + reliability priors); (2) deterministic stdlib-only detector (detect_candlestick_patterns.py) as objective baseline; (3) reconcile: agree → combined confidence; disagree → explain which to trust, lower confidence; (4) report template. Core principles: "Patterns are hypotheses; location and confirmation make them signals"; "Cross-check vision with rules"; "Latest bar is decisive"; "State confidence honestly"; "Always frame risk" (entry trigger, invalidation level, target). Quality standards: cite actual price levels, no vague descriptions; report conflicting patterns too; disclaimer. Verified live.
