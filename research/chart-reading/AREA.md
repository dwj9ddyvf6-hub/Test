# research/chart-reading/: what lives here

The chart reading masteries: the desk's complete written method for reading a chart, built from October 2026 onward, published as code plus written mastery so another LLM can learn the method and run it. The desk's `best_setups/` code itself lives with the desk tree; this area holds the mastery layer around it.

## Collections

- `skills/local-chart-read/`: the chart-read skill. Pass A geometry (levels, structure, measured moves, computed in code) and the perceptual Pass B read, with the trigger watcher.
- `skills/local-stock-analysis/`: the full stock analysis skill. One protocol that runs Pass A geometry, the Pass B perceptual read, edge-labeled strategy lenses, market context, and a rigorous synthesis whenever a ticker is named. Its fragments carry the technical analysis mastery addendum and the external canon addendum.
- `mastery-program/`: the chart reading mastery and annotation program (the CRA work): how reads are annotated, graded, and turned into mastery instead of one-off opinions.
- `best-setups/`: the Best Setups fix and best-practices work: how the setup canon was audited, repaired, and held to its own evidence.
- `ict-smc-liquidity/`: the ICT and smart-money-concepts liquidity setup evidence study: which of those concepts survived contact with the desk's own data.
- `llm-chart-reading/`: the study of how LLMs read charts, what they systematically miss, and the protocol corrections that came out of it.
- `setups-redesign/`: the setups product redesign: the setup catalog reshaped as a product a reader can actually use.
- `terminal-chart-cures/`: the terminal chart cures: defects found in the terminal's chart surfaces and the verified fixes, with the verification method written down.

## Standing rules of this corpus

- A read is a protocol, not an impression: geometry first, perception second, lenses labeled by edge, synthesis last.
- Every mastery claim in here was earned against the desk's own charts and data, and the falsified ideas are kept next to the surviving ones, named as falsified.

Exact file counts and blob hashes for this area live in the root INDEX.json, under the path prefix `research/chart-reading/`.
