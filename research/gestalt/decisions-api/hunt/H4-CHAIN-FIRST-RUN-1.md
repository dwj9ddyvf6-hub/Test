## Part 1: Chain-first screen run 1

Method: per name, ATM IV at the front expiry, the next expiry and the expiry nearest 30 DTE; term as front minus next in vol points, z-scored inside its own expiry class (daily-expiry names measure Mon 2026-11-16 against Fri 2026-11-20, weekly names measure Fri 2026-11-20 against Fri 2026-11-27, so term is only compared inside a class); skew as the 25 delta put IV minus the 25 delta call IV at the IV30 expiry; implied move to the front expiry from the ATM straddle. Class term means: weekly class plus 12.3 vol points (sd 6.5), daily class minus 12.3 (sd 9.3). Cross-sectional median skew: plus 4.5 vol points. Own-history percentiles: the desk IV ledger holds one session (2026-11-13) for 13 names, far below the 60 observation minimum in the CAND-CHAIN-1 registration, so no registered own-history extreme is claimed for any single name; cross-sectional ranks carry the grading, and the one-day change against that single ledger observation is printed where it exists, labeled n=1. Per the tempering law, this screen grades and ranks; a low rank is not a kill and a high rank is a nomination for the card process, not a trade.
