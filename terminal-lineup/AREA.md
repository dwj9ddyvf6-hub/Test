# terminal-lineup/: what lives here

The public terminal lineup: the tool site under site/ (104 tool pages), the forecast code under forecast/ (30 registry entries; inspect source bindings and evidence separately), build records, design documents, the oracle and the workflow scripts that built the tools.

Exact file count, byte total and captured revision: [the generated repository index](../INDEX.md). The matching entries in [INDEX.json](../INDEX.json) retain every path and blob hash.

Layout: root files (design documents, bug logs, build records, the lineup manifests THE-70-TOOLS.md and FORECAST-ENGINES-30.md, and the workflow scripts that built the tools), site/ (tool pages, source, assets and dated data), forecast/ (the forecast registry, implementations, grading and ledger), oracle/, records/ and specs/; use INDEX.md for measured counts. Start at THE-70-TOOLS.md.
