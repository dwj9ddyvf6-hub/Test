  What broke: the 5-minute book strip watcher republishes one

  "FAILED: publish exit 5 (SYNC ALREADY RUNNING...)". The defect

  publish should never need the whole tree, and a contended
  scoped publish should wait, not fail.

  longer invoke a whole-tree publish at all; its publish

  watcher's hashes describe the book records, not the publish
  target; the scoped census caught the drift and uploaded it.

  publish queue daemon (right shape at larger scale, new
  always-on machinery for a two-caller problem); Git Data API
  one-commit publishing for the whole sync (a rewrite of a

  offsets and jitter (probabilistic, the race survives).
  Blocker: site/test_book_strip_scoped_publish_20261109.py
