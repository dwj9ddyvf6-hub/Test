# ChartsLector component

`adapter.mjs` is a bounded local calculation over two date-aligned synthetic-or-caller-supplied OHLCV panels; it emits relative-strength, trend-stage, and ratio/momentum series. It does not fetch data, rank candidates, generate entries, size positions, or submit orders. `original.py` is an optional NumPy/Pandas parity implementation based on selected archived algorithm sources; additional archival modules and inert research/test source references are in archive_reference/README.md. Raw provider captures, panels, fitted results, and runtime trees are omitted. No blanket reuse license is granted by this collection; this is not a finding that owner-controlled publication is forbidden.

**Inputs:** aligned daily bars of at least 156 and at most 400 rows for instrument and benchmark; ISO timestamps strictly increasing; finite positive OHLC, coherent high/low, nonnegative volume. **Output:** per-session arrays for `rs26`, `rs78`, `rs156`, two run flags, stage code, ratio and momentum, with unavailable numeric values as null. `tests/chartslector-synthetic.test.mjs` exercises bounded shape and invalid-history behavior with generated bars only. This validates code invariants, not parity against live/past market data or usefulness.
