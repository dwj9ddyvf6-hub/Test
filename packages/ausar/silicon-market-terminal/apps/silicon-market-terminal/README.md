# Silicon Market Terminal

A dependency-free, local-first market-intelligence prototype inspired by the public feature surface of Unusual Whales. It is an independent UI and implementation; it does not copy their code or claim access to their private services.

## Run

From this directory, run:

```powershell
node server.mjs
```

Then open `http://localhost:4173`. Without `UW_API_KEY`, the terminal runs in **synthetic demo mode**. Every sample market value and trade is generated locally and is explicitly labeled as synthetic.

To enable the optional, read-only Unusual Whales connector, set `UW_API_KEY` in the server process environment before starting it. The key stays server-side and is never sent to the browser or written to this repository. The connector only proxies a small allowlist of documented GET market-data routes; it blocks writes and account-scoped watchlist/alert operations. A personal API plan may not allow commercial redistribution; obtain the appropriate license before serving vendor data to other users.

## Included workflows

- Market overview with market-tide-style call/put premium, sector pulse, movers, news, and event cards.
- Searchable options-flow table with filters, sorting, saved trades, and an estimate-quality cue.
- GEX and Greek exposure view with strike-level heatmap, walls, flip, and volume/OI basis switch.
- Dark-pool prints and price levels; congressional and insider activity; stock screener; event calendar; headlines.
- Ticker research, price chart, options chain, chart workspace, watchlists, custom alert rules, and a local risk/payoff calculator.
- Local persistence for watchlists, saved trades, alert rules, and UI preferences using browser storage.
- Vendor coverage map for the 86 teardown target families, with report links, research status, product lanes, and explicit implementation gaps.
- Confluence Lab: two separate manual candidates for Leadr’s public 55-field metadata table and its 17-leaf `v3Effective` path. Inputs are isolated by ticker; server/framework scoring remains unavailable.
- Sector Portfolio Lab: a local CSV-driven constructor for Danelfin’s published Low Risk/liquidity filters, sector ranking, five-per-sector selection, and equal-weight snapshot, with a dated membership-review and annual target-weight schedule. Scores and Proven Buy classifications are user supplied; the server-side AI Score is not recreated.
- Static GEX Lab: a local option-chain calculator for the published static gamma-exposure formula, using user-supplied prior-night OI and IV plus transparent Black–Scholes and call-positive/put-negative assumptions. Proprietary intraday positioning remains unimplemented.
- 15.87 Rule map: a manual-input calculator for the published prior-close expected move, five map lines, VIX regime bands, square-root funded range, weekly context, and a descriptive candidate-target band check. The opening-range setup engine and OI-derived second-wall layer remain unimplemented.
- Option strategy lab: a manual multi-leg expiration-payoff constructor for up to eight calls and puts, with exact piecewise breakevens, bounded/unbounded payoff labels, independent European Black–Scholes or American CRR binomial marks, and a deterministic 3×5 spot/IV sensitivity grid. American Greeks are finite-difference approximations, and invalid CRR probabilities are rejected. It uses user-entered values only and makes no vendor pricing-parity claim; optimizer ranking and sealed flow scoring remain outside scope.
- Options Activity Profile lab: a local CSV calculator for Bullflow’s published 20-session relative-volume baseline, point-in-time same-ET comparison, execution-side premium arithmetic, unusual-contract ranking, and four published flags. It treats uncovered dates as unavailable, requires explicit coverage markers to count zero-print sessions, and leaves sealed SigScore/alert logic out of scope.
- Filter Contract Lab: a local snapshot screener implementing a documented subset of Finviz’s `f=`, `o=`, and `t=` contract. It preserves AND across distinct filters, last-value-wins for repeated filter keys, ticker-list order, and sort direction; it does not provide Finviz data or generate pattern tags.
- Stock Rover Factor Profile Lab: a local cross-sectional ranker for all 23 published Value, Growth, Quality, and Sentiment inputs. It makes the R1–R4 desk choices explicit, limits two valuation inputs to sector-relative ranks, and leaves incomplete categories unscored; it does not implement vendor weights, Piotroski/Altman overlays, DCF, or margin of safety.
- Evidence graph that groups correlated vendor features by underlying source family, calls out the four point-in-time clocks, and keeps formula matching separate from forward trading evidence.
- Strategy Lab for local Date/Close CSV import, a long-or-flat SMA rule, one-bar signal delay, per-side transaction costs, chronological in/out-of-sample summaries, browser-local run summaries, and result CSV export.
- Read-only API connection status, local Morgue snapshot inspection, and GET /api/health/readiness for metadata-only pipeline state; the readiness response never returns market values or asserts source freshness.

## Current implementation status

This remains a partial, independent suite prototype. Exact vendor parity is 0/86. The implementation backlog classifies 69 families as shared-prototype-only, 8 as partial independent candidates (Leadr, Danelfin, SpotGamma, OptionStrat, Bullflow, Finviz, Stock Rover, and the 15.87 Rule), 5 as bounded-research-only follow-ups, 1 as a static package review without a vendor adapter, 1 as lacking a vendor-specific adapter, and 2 on-chain families as having no terminal surface. These implementation states are separate from the research scoreboard: 100 pass rows are 95 complete and 5 bounded-complete; the family registry is 81 complete and 5 bounded-complete. The source-backed roster still contains 86 families, not 92; the six-name difference remains unassigned because no six additional target identities are present in the source record.

The Strategy Lab is original research tooling, not a vendor strategy or execution simulator. It uses close-only data, delays each signal by one bar, charges the configured cost on entries and exits, and reports the chronological split without claiming predictive value. Uploaded CSV contents stay in the browser tab and are not persisted or sent to the local server. The user can download a JSON evidence bundle with canonical input rows, full analysis records, SHA-256 hashes, and explicit eligibility blockers; saved browser summaries still omit raw bars.

The Confluence Lab uses analyst-entered normalized submetric scores saved only in this browser and isolated by ticker. The 55-field view is a transparent candidate built from descriptive metadata; the separate 17-leaf view follows the observed `v3Effective` weighting and aggregation path where the client exposes it. Both leave market context unavailable without its separate framework payload. Raw feature transforms, source freshness, server-side imputation, and the production score remain unknown. Neither view is a live signal feed or exact product replica.
See [`../../research/leadr_labs/CONFLUENCE-LAB-IMPLEMENTATION.md`](../../research/leadr_labs/CONFLUENCE-LAB-IMPLEMENTATION.md) for the source mapping and calculation limits.

The Sector Portfolio Lab reads local CSV rows with `Ticker,Score,Sector,LowRisk,Avg3MVolume` and optional `ProvenBuySignal,AsOf,SnapshotComplete` columns. Repeated tickers are allowed across dates. The schedule uses quarterly membership and annual target-weight events anchored to the selected start date, and suppresses a selection when the latest prior snapshot is stale or lacks an explicit user completeness declaration. Files remain in browser memory and are not persisted or uploaded. Proven Buy priority is applied only within selected sectors; remaining slots use score rank. Tie ordering, calendar-month date clipping, and the seven-day snapshot window are local deterministic choices. This planner does not compute actual weight drift, returns, costs, or trades, and does not establish the vendor’s backtest results; see [`../../research/rea-teardowns/danelfin/PORTFOLIO-LAB-IMPLEMENTATION.md`](../../research/rea-teardowns/danelfin/PORTFOLIO-LAB-IMPLEMENTATION.md).

The Static GEX Lab reads one-underlying, one-date option-chain CSVs with `Ticker,AsOf,Spot,Strike,Type,OpenInterest,IV,DTE`. It calculates Black–Scholes gamma, convention-signed per-1% dollar GEX, strike concentrations, and the nearest zero crossing on a configurable spot grid. Files remain in memory and can be exported with contract-level calculated values. It does not estimate dealer inventory or reproduce SpotGamma’s intraday products; see [`../../research/rea-teardowns/spotgamma/GEX-LAB-IMPLEMENTATION.md`](../../research/rea-teardowns/spotgamma/GEX-LAB-IMPLEMENTATION.md).

The Option Strategy Lab accepts a same-underlying, same-expiration list of `type,side,strike,premium,contracts,multiplier` legs. It sums intrinsic value less entry premium at expiry, derives breakevens from the piecewise-linear payoff, and detects unbounded upside/downside from the aggregate call slope. The independent pricing scenario can use European Black–Scholes or an American CRR binomial tree with user-selected steps; American Greeks are finite-difference approximations. Values are held in browser memory for the tab and are not uploaded. It does not use vendor code/data or claim vendor pricing parity, and it does not estimate probabilities, search/rank candidates, or process live flow; see [`../../research/rea-teardowns/optionstrat/OPTIONSTRAT-LAB-IMPLEMENTATION.md`](../../research/rea-teardowns/optionstrat/OPTIONSTRAT-LAB-IMPLEMENTATION.md).

The Options Activity Profile Lab reads user-supplied local CSV rows with `Date,TimeET,Ticker,Contract,Expiry,Type,Strike,Size,Premium,Side,TradeType,OpenInterest`; optional `Timestamp`, `Source`, `TradeID`, `SideSource`, and `Cancelled` fields retain event and classification provenance. Relative-volume outputs require 20 prior dates and the selected session to have explicit `Available=true,ExportComplete=true` coverage rows plus cancellation status; a no-print date is zero only when declared complete, while missing or partial exports stay unknown. Raw source timestamps are checked against ET date/time, and duplicate source IDs are rejected. These are user-provided declarations, not independently verified market-wide coverage. The lab evaluates only the four published flags and does not call Bullflow, reproduce SigScore or sealed alert triggers, or validate predictive value; see [`../../research/rea-teardowns/bullflow/ACTIVITY-PROFILE-LAB-IMPLEMENTATION.md`](../../research/rea-teardowns/bullflow/ACTIVITY-PROFILE-LAB-IMPLEMENTATION.md).

The Filter Contract Lab reads a local snapshot CSV with a required `Ticker` or `Symbol` column and optional company, security type, exchange, index, sector, country, capitalization, valuation, price, volume, change, pattern-tag, and candlestick-tag fields. It implements a subset of the measured Finviz query grammar: cross-key AND, last-value-wins for repeated keys, exchange/sector/country/index selectors, the documented `cap_largeover` threshold, user-supplied pattern/candlestick tags, `o=` ordering, and `o=tickersfilter` order from `t=`. It excludes rows explicitly marked `ETF` and reports missing, excluded, and filtered tickers instead of silently dropping them. It does not recreate all 82 controls, custom Elite filters, live results, or Finviz’s server-side tagger; see [`../../research/rea-teardowns/finviz-screener/FINVIZ-LAB-IMPLEMENTATION.md`](../../research/rea-teardowns/finviz-screener/FINVIZ-LAB-IMPLEMENTATION.md).

The Stock Rover Factor Profile Lab reads one-decision-date snapshots with `Ticker,Sector,AsOf` plus all 23 published factor inputs. It ranks each metric with cross-sectional midrank percentiles, ranks Price/Tangible Book and Price/Sales within sector, averages inputs equally within each category, and averages the four categories equally. Missing values are not imputed: incomplete categories and composites remain blank. R1–R4 are documented desk reconstruction choices; the tool does not implement the safety overlays, vendor weights, DCF, or margin of safety and does not establish predictive value. See [`../../research/rea-teardowns/stockrover/STOCKROVER-FACTOR-LAB-IMPLEMENTATION.md`](../../research/rea-teardowns/stockrover/STOCKROVER-FACTOR-LAB-IMPLEMENTATION.md).

The 15.87 Rule map calculates the prior-close VIX expected move, half-move and full-move levels, VIX regime band, funded range at a user-entered elapsed time, weekly context, and a descriptive target-band check. It implements the public map only; the three-ticker breakout, fades, open-interest shortlist, touch accounting, and flow check remain unimplemented. Inputs are manual and held in the active page state. The published worked examples are not evidence of predictive edge. See [`../../research/rea-teardowns/azrael-1587/MAP-LAB-IMPLEMENTATION.md`](../../research/rea-teardowns/azrael-1587/MAP-LAB-IMPLEMENTATION.md).

This is a single-user local prototype. Login, billing, cloud sync, notifications, historical vendor entitlements, streaming delivery, broker/exchange execution, onchain analytics, and authenticated vendor runtime behavior are not implemented. Synthetic values must not be used for investment decisions.

## Shared evidence contract

Phase 4 has a versioned source registry, canonical observation and derived-feature schemas, cross-runtime SHA-256/stable-ID helpers, and fail-closed point-in-time/lineage eligibility helpers. The Option Strategy Lab emits a local user-assumption observation and model feature; the close-only Strategy Lab exports a content-hashed CSV input/result bundle. Unknown availability and coverage keep both decision and lineage eligibility blocked. The other labs have not yet been migrated. The local read-only server exposes the same contract at `GET /api/evidence-contract`; source hashes are not entitlement proof, synthetic fixtures are never decision data, and gaps remain explicit. See [`EVIDENCE-CONTRACT.md`](./EVIDENCE-CONTRACT.md) for source boundaries, semantics, and remaining integration work.

The Data & Privacy screen also provides a versioned, local-only Morgue snapshot metadata adapter at `GET /api/engines/morgue/v1/snapshot`. It returns the saved feed's as-of date, generation time, SHA-256, and section-presence flags; it does not return ticker values or ingest market measures. Rights, source availability, and point-in-time validation remain unknown, so decision, performance-claim, and order use are blocked. See [`MORGUE-ADAPTER.md`](./MORGUE-ADAPTER.md).
