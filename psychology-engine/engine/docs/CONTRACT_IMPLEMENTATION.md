# Contract implementation boundary

The preserved 1.0.0 contract is a design input, not a declaration of complete implementation. This research engine implements a bounded subset.

| Contract area | Implemented | Remaining / explicit abstention |
|---|---|---|
| Authority | No order/size/exit/risk/veto functions; Tensor unchanged; outputs marked advisory | Frozen-policy integration and utility evaluation not implemented |
| Evidence clocks | Immutable source publication, first-seen, provider/local/extraction clocks; available_at gating throughout | Imported historical clocks are attestations, not independently verified |
| Provenance | Raw response hashes for adapters, source population, mapping/config versions, source URL; semantic revisions immutable | Full author/origin/exposure lineage, licenses, claim spans and retention governance can remain unknown |
| Closed bars | Price-return import requires closed bar and context/availability validation | Exchange calendars and adjusted executable fills are not supplied or validated externally |
| Measurement | Named proxies, units, populations, freshness and source deduplication; no universal fear/greed scalar | Latent state, covariance, author caps, stable-panel decomposition and semantic claim extraction not fitted |
| Outputs | Contract-shaped descriptive envelope with evidence, quality, clocks, stage and advisory boundary | Forecast distributions and estimates remain empty; no omnibus confidence, calibration or market validation claim |
| Patterns | Four transparent descriptive detectors, source-history and availability guards | The supplied 16-card registry is not executable merely because it is documented; all 16 cards preserved with checksum verification; implementation status separately mapped |
| Evaluation | Chronological baselines, explicit label availability, nonoverlap and gap-aware costs; proxy forecast vintage reconstruction | Nested selection, event embargo, block inference, multiple-testing ledger, prospective validation and Tensor opportunity comparison not implemented |
| Drift | Source failure logs and cutoff-aware health; missing/stale abstention | Stable-panel composition and semantic/model drift monitors require additional data |

No FinBERT, structured LLM extraction, claim probability model, author tracking or latent psychological-state model runs in this package. The transparent lexicon is a baseline with unresolved linguistic errors. The proxy forecast's persistence/drift point values are model estimates, not calibrated distributions or inferred private beliefs. Forecast/evaluation examples are generated fixtures. The separately labeled observed-wikimedia example imports two previously captured CC0 pageview counts; its detectors and forecast abstain.
